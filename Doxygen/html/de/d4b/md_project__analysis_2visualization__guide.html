可视化指南

推荐的可视化工具

  1. ParaView
    • 功能强大的开源可视化工具
    • 支持AMReX的plotfile格式
    • 可绘制等值线、矢量场、流线等
  2. VisIt
    • 专业的科学可视化工具
    • 对CFD数据有良好支持
    • 可处理大型数据集
  3. Matplotlib (Python)
    • 用于创建自定义图表
    • 适合处理1D数据
    • 可与NumPy配合使用

建议的可视化图表

1. 密度分布图

用途: 显示两相流体的密度分布

类型: 等值线图或彩色云图

变量:

  • AlphaRho1 (相1密度×体积分数)
  • AlphaRho2 (相2密度×体积分数)
  • 总密度 (AlphaRho1 + AlphaRho2)

示例命令 (ParaView):

paraview --data=plt00000

2. 体积分数分布

用途: 显示相界面位置

类型: 等值线图或彩色云图

变量:

  • Alpha1 (相1体积分数)
  • Alpha2 (1 - Alpha1，相2体积分数)

重要值:

  • Alpha1 = 0.0: 纯相2
  • Alpha1 = 1.0: 纯相1
  • 0.0 < Alpha1 < 1.0: 混合区

3. 压力场分布

用途: 显示压力波和激波

类型: 等值线图或彩色云图

变量:

  • 从能量方程计算的压力

特点:

  • 激波表现为压力突变
  • 膨胀波表现为压力下降

4. 速度矢量场

用途: 显示流体速度分布

类型: 矢量图或流线图

变量:

  • XMom, YMom (动量分量)
  • 速度: u = XMom / rho, v = YMom / rho

特点:

  • 可显示流动方向和速度大小
  • 可观察涡旋和流动分离

5. 网格加密图

用途: 显示AMR网格的加密情况

类型: 网格线图

变量:

  • 网格级别信息

特点:

  • 颜色编码显示不同网格级别
  • 可观察网格如何适应物理特征

6. 时间序列分析

用途: 显示物理量随时间的变化

类型: 时间序列图

变量:

  • 任意物理量

示例:

  • 相界面位置随时间变化
  • 压力峰值随时间变化
  • 能量守恒情况

数据导出方法

1. AMReX 内置输出

可视化技巧

1. 多变量对比

  • 分屏显示: 同时显示密度和压力
  • 叠加显示: 在速度场中叠加密度等值线
  • 时间动画: 创建时间序列动画

2. 数值精度检查

  • 密度守恒: 检查总质量是否守恒
  • 能量守恒: 检查总能量是否守恒
  • 压力合理性: 检查压力是否为正

3. 网格收敛性分析

  • 不同网格分辨率: 比较不同网格大小的结果
  • 误差估计: 分析AMR误差估计的准确性
  • 收敛速度: 计算数值解的收敛速度

常见问题及解决方案

1. 数据量过大

解决方案:

  • 减少输出频率
  • 使用降采样
  • 只输出感兴趣的区域

2. 可视化软件崩溃

解决方案:

  • 减少同时加载的时间步
  • 降低数据精度
  • 使用更高效的可视化格式

3. 相界面模糊

解决方案:

  • 增加网格分辨率
  • 使用更高阶的重构格式
  • 调整体积分数的显示范围

4. 激波捕捉不准确

解决方案:

  • 检查数值通量计算
  • 调整CFL数
  • 使用更适合激波的数值格式

示例可视化命令

ParaView

# 打开数据
paraview --data=plt00000
# 加载多个时间步
paraview --data=plt*
# 创建等值线
Filters → Contour
# 创建矢量场
Filters → Glyph
# 创建流线
Filters → Stream Tracer

VisIt

# 打开数据
visit -o plt00000
# 添加等值面
Add → Contour
# 添加矢量
Add → Vector
# 创建动画
Controls → Animation

Python/Matplotlib

import numpy as np
import matplotlib.pyplot as plt
# 读取数据
data = np.loadtxt('data.dat')
x = data[:, 0]
rho = data[:, 1]
# 绘制密度分布
plt.plot(x, rho)
plt.xlabel('Position')
plt.ylabel('Density')
plt.title('Density Distribution')
plt.show()
