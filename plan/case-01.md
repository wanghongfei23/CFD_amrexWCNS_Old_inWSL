# 用于自编结构网格代码的详细提示词：二维楔形域中的汇聚激波冲击双界面 air/SF6/air 算例

你要帮助我在现有的二维可压缩多组分流代码基础上，添加一个新的算例。  
我已有的代码已经能计算：

- 二维结构网格
- 矩形计算域
- 平面激波冲击平面扰动界面
- 可压缩 Euler 或 Navier–Stokes 型守恒格式
- 多组分/单组分中的至少一种
- 激波捕捉格式已经存在

现在要新增的算例不是矩形域，而是**二维楔形/扇形收缩域中的汇聚 Richtmyer–Meshkov 不稳定性算例**。  
该算例基于文献：

- Biamino et al., 2015, *On the possibility of studying the converging Richtmyer–Meshkov instability in a conventional shock tube*

---

## 1. 目标

请你基于我已有的二维结构网格求解器，设计并实现一个新算例模块，使其能够模拟如下过程：

1. 左侧空气中的平面入射激波，马赫数约 `Ms = 1.15`
2. 激波进入第一道 `air/SF6` 椭圆界面（气体透镜）
3. 平面激波折射为向右侧 apex 会聚的柱形/近柱形激波
4. 该会聚激波在 `r = 0.1 m` 附近撞击第二道带单模扰动的 `SF6/air` 界面
5. 出现界面相位反转与增长
6. 激波到达 apex 固壁后反射，形成 re-shock，再次作用于混合层

我希望新增的代码尽量满足以下要求：

- 尽量复用原有守恒变量、数值通量、时间推进和边界处理框架
- 重点新增“**楔形几何 + 结构网格映射 + 双界面初始化 + 初始平面激波初始化 + 结果输出**”
- 代码结构清晰，便于后续做网格收敛和参数研究
- 优先保证能跑通、结果合理，再考虑高阶优化

## 2. 物理与几何模型

### 2.1 几何概述

计算域是一个二维对称楔形收缩通道：

- 右端为 apex（顶点）
- 左端开口较宽
- 上下边界是两条直线壁面
- 楔形半顶角为 `15°`
- 总夹角为 `30°`

建议采用笛卡尔坐标系 `(x, y)`：

- 将 apex 放在 `x = 0`
- 计算域向左延伸，即 `x < 0`
- 中心线为 `y = 0`
- 上下壁面分别为

```text
y_top(x) =  (+)(-x) * tan(15°)
y_bot(x) =  (-)(-x) * tan(15°)
```

因为 `x <= 0`，也可写成：

```text
y_top(x) = |x| tan(15°)
y_bot(x) = -|x| tan(15°)
```

建议计算域的 x 范围取：

```text
x in [-0.22, 0.0] m
```

这样可以包含：

- 第一界面位置 `r ≈ 0.159 m`
- 第二界面位置 `r ≈ 0.100 m`
- apex 附近反射区
- 左侧足够长的入射激波传播空间

---

### 2.2 极坐标与半径定义

该文献中的界面是相对于 apex 定义的极坐标曲线，因此建议统一使用以下极坐标定义：

- 极点在 apex，即 `(x, y) = (0, 0)`
- 半径：

```text
r = sqrt(x^2 + y^2)
```

- 极角：

```text
theta = atan2(y, -x)
```

注意这里要让 `theta = 0` 对应中心线向左方向，因为 shock 从左向右传播，而文献中的界面曲线是围绕 apex 向左张开的。

因此更推荐使用：

```text
theta = atan2(y, -x)
r     = sqrt(x^2 + y^2)
```

于是：

- 当点在中心线上且位于 apex 左侧时，`theta = 0`
- 上壁方向 `theta > 0`
- 下壁方向 `theta < 0`
- 楔形边界角度范围是

```text
theta in [-15°, +15°]
```

即

```text
theta in [-0.261799..., +0.261799...] rad
```

## 3. 两个界面的精确定义

### 3.1 第一界面：air / SF6 气体透镜界面

文献给出的极坐标表达式是：

```text
r1(theta) = r0 * (1 - e) / (1 - e cos(theta))
```

其中：

- `r0 = 0.159 m`
- `e = Wt / Wi`
- 文献给出：
  - 入射激波速度 `Wi = 394 m/s`
  - 在 SF6 中的透射激波速度 `Wt = 169 m/s`
- 因此：

```text
e = 169 / 394 ≈ 0.429
```

文献中近似写成 `0.42`，建议统一采用：

```text
e = 0.42
```

所以第一界面取：

```text
r1(theta) = 0.159 * (1 - 0.42) / (1 - 0.42 * cos(theta))
```

即：

```text
r1(theta) = 0.159 * 0.58 / (1 - 0.42 cos(theta))
```

这个界面将空气和 SF6 分开：

- `r > r1(theta)`：第一界面左侧外部区域，空气
- `r < r1(theta)` 且在第二界面之外：中间区域，SF6

更准确地说，整个三层介质分区要结合第二界面共同判断，见后文。

---

### 3.2 第二界面：带单模扰动的 SF6 / air 界面

文献给出的表达式：

```text
r2(theta) = 0.1 - 0.0015 * (1 - cos( 2*pi*theta / theta0 ))
```

其中：

```text
theta0 = arctan(0.04 / 0.15)
```

计算得：

```text
theta0 ≈ 0.2606 rad
```

这与 `15° = 0.261799 rad` 非常接近，实际实现时可取：

```text
theta0 = atan(0.04 / 0.15)
```

或者直接：

```text
theta0 = 15° in radians
```

建议严格使用文献值：

```text
theta0 = atan(0.04 / 0.15)
```

第二界面代表：

- 外侧是 SF6
- 内侧靠近 apex 的区域是 air

所以最终三层分区是：

1. 第一界面外侧：air
2. 第一界面和第二界面之间：SF6
3. 第二界面内侧：air

即：

```text
air / SF6 / air
```

## 4. 三层介质区域判定逻辑

对每个网格点 `(x, y)`：

先计算：

```text
r = sqrt(x*x + y*y)
theta = atan2(y, -x)
```

再计算：

```text
r1 = 0.159 * (1 - 0.42) / (1 - 0.42 * cos(theta))
r2 = 0.1 - 0.0015 * (1 - cos(2*pi*theta / theta0))
```

其中：

```text
theta0 = atan(0.04 / 0.15)
```

区域分类建议如下：

### 方法一：按半径判断（推荐）

如果：

```text
r > r1
```

则为外层空气区：

```text
material = AIR_OUTER
```

如果：

```text
r2 < r <= r1
```

则为中间 SF6 区：

```text
material = SF6
```

如果：

```text
r <= r2
```

则为内层空气区（靠近 apex）：

```text
material = AIR_INNER
```

两层空气的热力学参数可相同，只是为了初始化和后处理时逻辑清晰，可以在标记上区分，也可以统一视为 AIR。

---

### 方法二：用组分质量分数表示

如果你的程序是单一多组分模型，可以只保存一个 `Y_SF6`：

- 外层空气区：`Y_SF6 = 0`
- 中间 SF6 区：`Y_SF6 = 1`
- 内层空气区：`Y_SF6 = 0`

如果需要减少 Gibbs 振荡或避免界面严格零厚度，可以对两个界面都用双曲正切平滑：

```text
H(phi, delta) = 0.5 * (1 - tanh(phi / delta))
```

例如：

- `phi1 = r - r1(theta)` 表示相对第一界面的带符号距离近似
- `phi2 = r - r2(theta)` 表示相对第二界面的带符号距离近似

不过如果你现在已有 sharp initialization 的界面处理，先直接分段赋值即可。

## 5. 气体参数与初始热力学状态

建议先采用理想气体模型。

### 5.1 空气参数

```text
gamma_air = 1.4
R_air     = 287.0 J/(kg·K)
```

### 5.2 SF6 参数

推荐：

```text
gamma_sf6 = 1.09
R_sf6     = 56.9 J/(kg·K)
```

### 5.3 初始静止状态

文献没有强调特别的初始绝对压强和温度，建议统一采用常温常压：

```text
p0 = 1.0e5 Pa
T0 = 293.0 K
u0 = 0
v0 = 0
```

由状态方程得到密度：

#### 外层和内层空气

```text
rho_air = p0 / (R_air * T0)
        ≈ 1.19 kg/m^3
```

#### SF6

```text
rho_sf6 = p0 / (R_sf6 * T0)
        ≈ 5.99 kg/m^3
```

所以初值可设：

- AIR：`rho = 1.19`
- SF6：`rho = 5.99`
- 全域 `u = 0, v = 0, p = 1e5`

### 6.1 目标

在左侧空气区初始化一道沿 `+x` 方向传播的平面激波，马赫数：

```text
Ms = 1.15
```

文献给出的激波速度约：

```text

v1   = 0

```

### 6.3 激波后状态（区2）

### 6.4 初始激波位置

建议将平面激波初始位置放在：

```text
x_s = -0.20 m
```

即：

- 当 `x < x_s`：为激波后状态（空气）
- 当 `x > x_s`：为激波前状态，但要再根据材料区分 AIR 或 SF6

注意一个关键点：

**激波初始时应仅位于第一界面左侧的空气区，不要直接把激波后状态赋到 SF6 或第二界面后方。**

推荐初始化逻辑：

1. 先按双界面给整个域赋静止的三层气体状态

3. 如果 `x < x_s` 的区域穿过了第一界面，需要小心：更物理的做法是把初始激波位置设在第一界面左侧足够远处，使其不穿过透镜界面

因此推荐：

```text
x_s = -0.20 m
```

同时注意第一界面中心线上位置是：

```text
x = -0.159 m
```

所以 `x_s = -0.20 m` 是合理的，激波完全位于第一界面左侧。

## 7. 计算域与结构网格建议

你当前是结构网格代码，因此建议仍采用**逻辑矩形网格 + 物理域映射**的方式，而不要直接切换成非结构。

---

### 7.1 逻辑坐标

引入计算坐标：

```text
xi   in [0, 1]
eta  in [0, 1]
```

其中：

- `xi` 对应流向，从左边界到 apex
- `eta` 对应横向，从下壁到上壁

---

### 7.2 建议映射方式

令：

```text
x = xL + (xR - xL) * xi
```

其中：

```text
xL = -0.22
xR =  0.0
```

对于给定的 `x`，上下壁位置分别为：

```text
y_bot(x) = -(-x) * tan(alpha)
y_top(x) =  (+)(-x) * tan(alpha)
alpha = 15° = pi/12
```

则：

```text
y = y_bot(x) + (y_top(x) - y_bot(x)) * eta
```

因为

```text
y_top - y_bot = 2(-x)tan(alpha)
```

所以也可写成：

```text
y = (2*eta - 1) * (-x) * tan(alpha)
```

这个映射非常适合结构网格，简单稳健。

---

### 7.3 网格点生成公式

对 `i = 0 ... Nx-1`, `j = 0 ... Ny-1`：

```text
xi_i  = i / (Nx - 1)
eta_j = j / (Ny - 1)

x(i,j) = xL + (xR - xL) * xi_i
y(i,j) = (2*eta_j - 1) * (-x(i,j)) * tan(alpha)
```

其中：

```text
alpha = 15° = pi / 12
```

---

### 7.4 apex 奇异性处理

由于 `x = 0` 时上下壁收缩到 `y = 0`，严格几何上 apex 是奇点。结构网格实现时建议不要让最右侧列真正落在 `x = 0`，否则一个 `i` 列会全部塌陷成一个点。

推荐两种方法：

#### 方案 A：截去 apex 小区域（推荐）

令右边界不取 `0`，而取：

```text
xR = -x_cut
```

例如：

```text
x_cut = 0.5 mm = 5e-4 m
xR = -5e-4 m
```

这样仍然保留 apex 附近的波反射过程，但避免网格退化。

右边界设为固壁。

#### 方案 B：保留 apex 但采用特殊单元退化处理

这对现有矩形结构网格代码改动较大，不推荐优先做。

**强烈建议先用方案 A。**

---

### 7.5 推荐网格尺度

如果你现在是 first implementation，建议先用：

```text
Nx = 1200
Ny = 240
```

然后根据映射自动形成变截面网格。

更实用的分级测试：

#### 粗网格
```text
Nx = 800
Ny = 160
```

#### 中网格
```text
Nx = 1200
Ny = 240
```

#### 细网格
```text
Nx = 1800
Ny = 360
```

因为横向宽度随 x 变化，靠近 apex 处实际物理网格会自然变小。  
这对解析会聚激波有利，但也会降低时间步长，所以 CFL 要适当保守。

## 8. 方程形式与几何处理建议

### 8.1 最省事的实现路径

如果你原始代码是标准笛卡尔守恒方程：

```text
∂U/∂t + ∂F/∂x + ∂G/∂y = 0
```

最简单的新增方案不是改成极坐标方程，而是：

- 仍然在物理平面 `(x,y)` 上求解二维 Euler / NS
- 使用**曲线结构网格映射**
- 通量在计算坐标下离散，或者直接在物理坐标做有限体积离散
- 几何收缩效应由真实物理边界体现，而不是源项体现

这和文献实验最一致，也最适合你现有代码扩展。

---

### 8.2 如果你已有曲线坐标有限体积框架

则可在计算域 `(xi, eta)` 中写成：

```text
∂(J U)/∂t + ∂F_hat/∂xi + ∂G_hat/∂eta = 0
```

其中：

- `J` 为雅可比
- `F_hat, G_hat` 为变换后的反变通量

建议 AI 优先复用现有曲线网格模板；  
如果你原来还没有曲线网格模块，则需要新加：

1. 网格点坐标数组 `x(i,j), y(i,j)`
2. 单元面积
3. 每个面法向量与面长
4. 基于几何量的有限体积通量计算

---

### 8.3 对 AI 的实现要求

请 AI 明确完成：

- 逻辑矩形网格到楔形物理域的映射
- 单元中心、顶点、面心几何量计算
- 四个面的外法向与长度计算
- 面通量用原有 Riemann 求解器计算

## 9. 边界条件

### 9.1 左边界

如果采用“初始场中嵌入平面激波”的方法，则左边界建议设为：

- 非反射流出边界
- 或简单外推边界

因为主要波系从左往右离开左边界的可能性很小，早期阶段影响不大。

---

### 9.2 上下边界

建议先采用：

- **滑移绝热壁**

实现方式：

- 法向速度镜像反射
- 切向速度不变
- 压力、密度外推或由 Riemann/ghost cell 一致处理

由于文献的重点不是边界层，所以先不要上无滑移。

---

### 9.3 右边界（apex 截断边界）

如果采用截断 apex 的方案，例如右边界在：

```text
x = -5e-4 m
```

则此边界应设为：

- **固壁反射边界**

这会产生与文献中 apex end wall 类似的反射激波。  
只要截断距离足够小，反射时序与波形会比较接近。

## 13. 混合气体与状态方程建议

若使用单一组分输运变量 `Y = Ysf6`，则：

```text
Rmix = Y*Rsf6 + (1-Y)*Rair
```

比热比 `gamma` 的混合处理有几种方法。最稳妥的是基于定压/定容比热混合：

```text
cv_air = R_air / (gamma_air - 1)
cp_air = gamma_air * cv_air

cv_sf6 = R_sf6 / (gamma_sf6 - 1)
cp_sf6 = gamma_sf6 * cv_sf6

cv_mix = Y*cv_sf6 + (1-Y)*cv_air
cp_mix = Y*cp_sf6 + (1-Y)*cp_air
gamma_mix = cp_mix / cv_mix
R_mix = cp_mix - cv_mix
```

然后状态方程：

```text
p = (gamma_mix - 1) * rho * e
```

或者：

```text
p = rho * R_mix * T
```

如果你的代码暂时不支持混合 gamma，可先在 sharp interface 假设下用材料标签控制局部 `gamma` 和 `R`。
